# 设计说明：小天鹅舞曲 · 瓷偶世界线

## 1. 概念

四只瓷白小天鹅在月夜湖面上起舞。她们停留过的每个姿态，都会在身后冻结成一尊瓷偶，沿四条"世界线"升起——时间被做成了可以触摸的雕塑。

一句话：**把"四小天鹅"的队形变成四条并行的时间线**。参考 Worldline Dancer 的"历史即雕塑"机制，但换了一个完全不同的意象：不是一个人的世界线，而是四个被编舞绑在一起的人。

## 2. 与参考作品的关系

| 参考（Worldline Dancer） | 本作 |
| --- | --- |
| 单人舞者的历史姿态冻结成残影 | 四只瓷偶的同步姿态冻结成四条世界线 |
| 世界线 = 6 手柄 Catmull-Rom + twist/stretch | 4 条独立世界线（当前 v1 只读，编辑留待 v2） |
| 抓取过去 → 舞者飞回去 | **抓住任意一尊残影 → 四只一起回到那一刻**（冻结雕塑，她沿静止的世界线回溯） |
| 模糊/玻璃/金箔/霓虹残影材质 | 瓷白半透明 + fresnel + 新生暖光 + 羽毛状拖尾 |
| 黑盒剧场 + 单追光 | 月夜湖面 + 冷月光 + 暖脚光 + 镜面倒影 + 月光路径 |
| 参考视频原声 | 柴可夫斯基《四小天鹅舞曲》公版曲目；采用用户提供的参考演出视频音轨 |

没有复用参考作品的代码或素材；只借鉴"历史姿态 → 世界线 → 可回溯"这一机制。

## 3. 五幕结构（与音乐段落严格对齐）

音乐：音轨已裁掉开头 0.67s 静音；**90.2s 音乐结束，之后是观众掌声直到 103.0s**。实测 bpm≈104.37（拍长 0.5749s，首拍 0.014s），参考演出视频原声（柴可夫斯基公版曲目）。舞蹈在 89.6s 收势、90.2s 起鞠躬，掌声只作谢幕背景。段落表在 `src/score.js`，HUD 的幕名直接读它：

| 幕 | 音乐段落 | 起止 | 画面 |
| --- | --- | --- | --- |
| i · 入场 | intro | 0 – 10s | 横排手链站定、呼吸与小跳准备 |
| ii · 队列 | theme | 10 – 32s | 基本小跳、整排左右摆、横移 |
| iii · 展翅 | middle | 32 – 66s | 侧/后伸腿（à la seconde / arabesque）与小跳交替 |
| iv · 回旋 | reprise | 66 – 92s | 更快的腿花、横移与头部左右 |
| v · 终幕 | coda | 80.0 – 89.6s | 收势、深 plié |
| vi · 谢幕 | outro | 89.6 – 96.8s | 音乐最后一小节收势，90.2s 掌声响起时深鞠躬；掌声中起身、保持手链退场，舞台光 3s 内暗下 |

音乐：**参考视频原声（final）**（103.7s，bpm≈101.7，柴可夫斯基公版曲目；音轨抽自用户提供的演出视频），播放头 = 时间轴 T；冻结时磁带停转，回溯后重新对齐。详见 `reference-video.md` 与 `music-notes.md`。

## 4. 交互

| 操作 | 效果 |
| --- | --- |
| 拖拽 / 滚轮 | 旋转、远近（OrbitControls，带阻尼；5s 无操作后缓慢自动环绕） |
| 悬停残影 / 过去的线 | **那个时刻的身影浮现**：四只小天鹅在那个瞬间的整整一组身影（手链仍连着）出现在世界线上的对应位置，光标旁显示 `−X.X s`；光标变抓取手势 |
| **按住残影** | 抓住她的过去：四只瓷偶一起回到那一刻；雕塑冻结（世界线静止），拖动可沿雕塑滑动选择时刻 |
| 松开 | 回到"现在"：从选中的时刻继续播放，音乐从该时刻续上 |
| `空格` / `F` | 冻结 / 继续（音乐磁带停转、雕塑定格） |
| `M` | 静音 |
| `H` | 隐藏 / 显示界面 |
| `R` | 重新开始 |
| 面板滑杆 | 历史长度 6–20s；残影密度 1–6 档 |

手感参数（都写在代码里）：抓取时冻结雕塑但时间轴跳到过去；残影拾取半径 34px（触摸 66px）；自动环绕延迟 5s；UI 面板 6s 无操作淡出。

## 5. 美术指导

**瓷偶**：暖白瓷 + clearcoat 1.0 + 低粗糙 + 微虹彩（0.38）+ 少量金饰（发冠/颈链/发带/鞋带）。12 个刚体部件：躯干（车削收腰）、波浪瓷纱裙、头/发髻/小冠、交叉双臂、收拢翅壳+尾羽、分段腿与足尖鞋。总高 1.65m，脚底贴地。

**舞台**：黑盒 + 月夜湖面。
- 地面：Reflector 镜面 + 半透明水膜（极淡的潮汐高光）；
- 光：单一冷月光追光（从上前方）、半球补光、两盏冷轮廓光（背后/侧后）、暖脚光；
- 天空：深蓝黑渐变 + 星点 + 月晕 + 月亮（硬核只在主相机可见，避免在湖面变成气泡）；
- 湖面月光路径：一条加性的柔光带；
- 空中的浮尘与薄雾；
- 后期：ACES + 轻 bloom + 色调压暗（exposure 0.78）。

**排布**：四只并排、肩并肩站成一条手链（间距 0.66m，接近真实四小天鹅的肩距），面朝 +Z（观众），双臂在胸前交叉、手与邻鹅相握（两段臂 IK 保证手链在呼吸/跳跃/转身时不断）。**脊柱两段**（骨盆 body + 胸 chest）让身体有 S 形曲线；**腿两段 + 足尖鞋**，支撑脚由正向运动学反推髋高贴地。每条世界线从各自骨盆 anchor 出发、向 −Z/+Y 升起，左右成扇形散开（`createWorldlines` 的 side/fan 参数）。

## 6. 音乐

- 曲目：柴可夫斯基《天鹅湖》No.13 IV《四小天鹅舞曲》（公版）。
- **音轨直接取自用户提供的参考演出视频**（ffmpeg 抽出 AAC → `assets/audio/swan-lake-source.mp3`，103.7s，bpm≈101.7）。
- 播放模型：Web Audio `AudioBufferSourceNode`，播放头 = 作品时间轴 T；冻结时磁带停转（rate→0.05 + 渐隐），解冻/回溯后从新的 T 重新对齐。
- 来源、分析与复刻说明见 `reference-video.md`。

## 7. 技术架构

```
index.html           开场门禁 + HUD
src/main.js          时间轴 T、渲染（RenderPass + Bloom + OutputPass）、相机、拾取/回溯交互
src/stage.js         湖面/月光/追光/星尘/雾/月光路径/水膜
src/swan.js          程序化瓷偶（12 刚体部件）+ 8s 解析式编舞 + 姿态捕获
src/worldline.js     6 控制点向心 Catmull-Rom → 241 原始点 → 160 点弧长 LUT → 平行传输朝向
src/ghosts.js        快照环形缓冲（capacity 80）+ 12 个 InstancedMesh + 年龄淡出 + 排序 + 拾取数据
src/music.js         参考视频原声播放 + 播放头跟随 T + 磁带停转
src/score.js         时长 / bpm / 段落（音乐、编舞、HUD 共用）
src/ui.js            安静 HUD（幕名跟随音乐段落、时钟、面板）
```

时间模型（与参考作品同构）：

```
T：音乐时间轴，只在播放且未冻结时前进
age = (T_ghost - birth) / history          // T_ghost 在冻结时保持不变 → 雕塑静止
world = worldline.matrixAtAge(age) × pose  // pose 是锚点相对的 12 部件世界矩阵
```

- 快照节流：每 0.2s（可被密度滑杆调密，但保证 `interval ≥ history/76` 不撑爆环形缓冲）。
- 四只天鹅同一次快照，共享实例次序；每个部件一个 InstancedMesh（共 12 个 draw call）。
- 冻结时 sculpture 用 `frozenSculptureT`，她可以沿静止的雕塑回溯；松手后残影引擎按 T 跳变平移出生时间，雕塑连续不闪。
- 性能：M2 Max 无头实测 ≈2.5ms/帧（渲染吞吐约 390fps），常规 60fps 有大量余量。

## 8. 已知限制 / 下一步

1. **分叉**：参考作品的"分叉出新的未来 + 旧未来碎成 glitter"还没做。计划：甩手分叉 → 一条世界线变成银色分岔、碎成羽毛粒子，新未来从该姿态进入另一段编舞。
2. **形象仍偏瓷偶**：17 部件骨架已包含脊柱、肘、膝、踝，但脸是留白瓷面、关节球仍可见（这是艺术方向）。要更像真人可以继续加五官、皮肤材质和手指抓握。
3. **世界线编辑**：参考作品的 Shift 手柄（bend/twist/stretch）未做；v2 可加"拉伸时间 → 回放变慢"。
4. 面部/手部细节、移动端竖屏取景、MP4 出片（可复用 `tools/capture.mjs` 的确定性帧思路 + 离线音频混流）。
