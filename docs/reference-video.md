## 复刻方式（诚实说明）

1. **配乐**：直接把视频音轨抽出为 mp3，网页里用 Web Audio 解码播放（`src/music.js`），播放头 = 作品时间轴 T；冻结时磁带停转、回溯后可重新对齐。
2. **队形 / 造型**：横排、肩并肩（间距 0.66m）、双臂在身前交叉、手与邻鹅相握（手链）、立脚尖；用两段臂 IK + 两段脊柱还原。
3. **编舞**：按标准四小天鹅的舞汇与视频可见动作（小跳、横移、侧伸腿 à la seconde、后伸腿 arabesque、头侧、收势）编排在音乐的 8 拍块上（`src/swan.js` 的 `BLOCKS` / `MOVES`），不是逐帧动作捕捉。
4. **为什么不是逐帧复刻**：该视频是抖音剪辑（多机位/推拉/特写+字幕），且本机无法加载 pose 估计的原生库（macOS 签名策略拒绝第三方 wheel 的原生扩展）。因此采用"音乐节拍 + 视频可见舞汇"的编排复刻；若需要更高保真，可提供一段**固定机位全景**片段，我可以做轮廓/关节追踪后重定向到瓷偶骨架。
5. **未复刻**：视频里的舞台布景（树林剪影）与字幕；本作用月夜湖面舞台替代（延续前一轮的美术设定）。
